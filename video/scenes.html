The problem

Your house knows a lot.
Nothing can ask it.

  • Which plumber fixed the water heater March 14 · $85
  • When the fridge warranty runs out 54 days
  • Where the spare key actually is unit 4B
  • That the leak was quoted, then forgotten open since Sept 21
Where it lives today
Chat threads. A drawer of receipts. Your head, at the worst possible moment.
Where it lives with Attic
One MCP endpoint. Spoken answers grounded in the record. Writes that persist.

So the house got a memory — and Alexa+ got a way to reach it.

Stateless assistant

Every house fact is fetched at answer time. The model never carries the house in its prompt.

Grounded, not guessed

Writes only count when a tool returns them, so "saved" in a reply is a fact, not a hope.

Self-hosted by default

One Node process, one SQLite file, a bearer token — running here on a small VPS behind TLS.
